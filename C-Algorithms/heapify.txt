if(r<n && array[r]>array[max]) max=r;

int temp=array[i];

in heapify we want every parent to be larger than its children so we start usually from the the last parent and compare it and if it has larger children we switch it with the largest one and then we do the same with the switched children to make sure it is larger than its children.
in heapsort algorithm first step is heap build the array and there we use heapify starting from the last parent to make the heap then in each step  we extract the largest elemet that is first element and switch it with the last element which is the last rightmost leaf then we do the heapify again to have the next max on the top.
in priority queue we extract the root which is first element in the array and has the highest prority and replace it with the last element which is the rightmost leaf and then do the heapify again so that elememts find their suitable places and we have highest pririty on the top again.
