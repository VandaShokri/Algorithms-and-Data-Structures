# 💻 Algorithms and Data Structures in C

A collection of core algorithmic implementations, advanced data structures, and problem-solving exercises developed during the Computer Engineering coursework at Politecnico di Torino. 

This repository demonstrates a strong foundation in low-level **C programming**, **pointer arithmetic**, **dynamic memory management**, and **algorithmic complexity analysis**—essential skills for efficient software development.

### 🗂️ Repository Structure

<details>
<summary><b> 🔍 Sorting and Searching </b></summary>
<br>
- Iterative and recursive implementations of foundational algorithms (Quicksort, Mergesort, Heapsort).
- Complexity analysis and optimization for time/memory efficiency.
</details>

<details>
<summary><b> 🧱 Dynamic Data Structures </b></summary>
<br>
- Custom implementations of Abstract Data Types (ADTs) using dynamic memory allocation in C.
- Linked Lists, Stacks, Queues, and Hash Tables.
</details>

<details>
<summary><b> 🌳 Trees and Graphs </b></summary>
<br>
- Binary Search Trees (BST) and balanced tree structures.
- Graph representations (Adjacency Matrix/Lists) and traversal algorithms (BFS, DFS).
- Shortest path algorithms (e.g., Dijkstra) and Minimum Spanning Trees.
</details>

<br>

> **Note:** This repository serves as a consolidated portfolio archive of academic coursework, unified here to showcase low-level C programming capabilities.
